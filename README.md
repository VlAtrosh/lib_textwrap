# lib_textwrap

Техническое задание на проект "Демонстрационный стенд модуля textwrap"
1. Общая информация
Название проекта: Демонстрационный стенд модуля textwrap
Заказчик: Учебная организация HERNY
Исполнитель: Группа HERNY
Цель проекта: Создать консольное приложение для наглядной демонстрации возможностей модуля textwrap стандартной библиотеки Python.

2. Описание задачи (что нужно сделать)
Необходимо разработать модульное консольное приложение, которое автоматически обрабатывает набор текстовых файлов, наглядно демонстрируя ключевые возможности модуля textwrap. Приложение должно позволять применять различные параметры форматирования к тексту и показывать результат "до" и "после" для понимания работы каждого инструмента.

3. Функциональные требования (что система должна уметь)
Система должна:

Читать текстовые файлы из предопределенной директории (data/).

Демонстрировать wrap(): Разбивать длинный текст на список строк заданной ширины.

Демонстрировать fill(): Переносить текст по словам для формирования абзаца заданной ширины.

Демонстрировать dedent(): Удалять общий начальный отступ из многострочного текста.

Демонстрировать shorten(): Обрезать длинный текст до указанной длины, добавляя многоточие.

Демонстрировать префиксы: Добавлять заданную строку (префикс) в начало каждой строки текста.

Поддерживать параграфы: Применять форматирование, сохраняя структуру пустых строк между параграфами (--preserve-paragraphs).

Обрабатывать несколько файлов: Применять выбранный режим форматирования ко всем .txt файлам в папке data/.

Выводить результат:

В консоль (по умолчанию).

В файл (сохранять отформатированный текст в указанный выходной файл или папку).

bash

Описание модулей
1. formatter.py - Ядро форматирования
Содержит чистые функции, напрямую использующие модуль textwrap.

format_fill(text, width, **kwargs): Применяет textwrap.fill().

format_dedent(text): Применяет textwrap.dedent().

format_shorten(text, length, **kwargs): Применяет textwrap.shorten().

add_prefix(text, prefix): Добавляет префикс к каждой строке текста.

apply_wrapper(text, width, preserve_paragraphs, **kwargs): Универсальная функция, использующая TextWrapper для комплексного форматирования (с опцией preserve_paragraphs).

2. file_handler.py - Работа с файловой системой
Отвечает за взаимодействие с файлами.

find_text_files(path): Рекурсивно находит все .txt файлы по заданному пути (файл или папка).

read_file(file_path): Читает содержимое текстового файла.

write_file(content, output_path): Записывает контент в файл.

ensure_output_dir(path): Создает выходную директорию, если она не существует.

3. cli.py - Логика демонстраций
Содержит функции, связывающие аргументы CLI с логикой форматирования.

process_single_file(file_path, args): Применяет все необходимые операции форматирования (dedent -> fill/shorten -> prefix) к одному файлу и возвращает результат.

handle_output(original_file_path, formatted_content, args): Определяет, куда выводить результат (в консоль или в файл) и вызывает соответствующие функции file_handler.

4. main.py - Главное приложение
Парсит аргументы командной строки с помощью argparse.

Получает список файлов для обработки через file_handler.find_text_files().

Для каждого файла вызывает cli.process_single_file().

Управляет общим потоком выполнения программы.

Работа с приложением
Приложение не имеет интерактивного меню, а настраивается через аргументы командной строки. Это позволяет легко интегрировать его в скрипты и автоматизировать обработку текста.

Основные аргументы:

input: Путь к файлу или папке с .txt файлами (обязательный).

-w, --width: Ширина строки для форматирования (по умолчанию 70).

--dedent: Флаг, указывающий на необходимость удалить общий отступ перед основным форматированием.

--prefix: Строка, которая будет добавлена в начало каждой строки.

--shorten: Обрезать текст до указанного количества символов (включая многоточие). Если указан этот аргумент, --width игнорируется.

--preserve-paragraphs: Флаг, сохраняющий структуру абзацев при форматировании.

--output-file: Путь для сохранения результата. Если обрабатывается несколько файлов, этот аргумент игнорируется, и нужно использовать --output-dir.

--output-dir: Директория для сохранения результатов обработки нескольких файлов.

Ключевые концепции модуля textwrap
1. fill(text, width)
Проблема: Длинный текст не помещается в консоль или область вывода.

Решение: Переносит текст по словам, создавая ровные строки заданной ширины.

Пример: textwrap.fill("очень длинный текст", width=10)

2. dedent(text)
Проблема: Многострочный код или текст с отступами в исходном файле выглядит некрасиво при выводе.

Решение: Удаляет общий для всех строк начальный пробельный отступ.

Пример: textwrap.dedent(" строка1\n строка2")

3. shorten(text, width)
Проблема: Нужно создать превью или анонс текста ограниченной длины.

Решение: Обрезает текст по словам до заданной ширины и добавляет многоточие.

Пример: textwrap.shorten("очень длинный текст", width=15) -> "очень [...]"

4. TextWrapper класс
Проблема: fill() и wrap() не хватает гибкости (например, нужно сохранять абзацы).

Решение: Предоставляет объект с большим количеством настроек ( replace_whitespace, drop_whitespace, initial_indent, subsequent_indent), который можно использовать повторно.
