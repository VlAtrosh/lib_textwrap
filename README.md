# lib_textwrap

## 1. Общая информация
Название проекта: Демонстрационный стенд модуля textwrap
Заказчик: Учебная организация HERNY
Исполнитель: Группа HERNY
Цель проекта: Создать консольное приложение для наглядной демонстрации возможностей модуля textwrap стандартной библиотеки Python.


## 2. Описание задачи (что нужно сделать)
Необходимо разработать модульное консольное приложение, которое в интерактивном режиме демонстрирует практическое применение ключевых инструментов модуля textwrap. Приложение должно показывать разницу в форматировании текста при использовании этих инструментов.


## 3. Функциональные требования (что система должна уметь)
Система должна предоставлять текстовое меню для выбора демонстрации.

Система должна демонстрировать работу fill() на примере форматирования абзацев.

Система должна показывать разницу в тексте до и после применения dedent().

Система должна демонстрировать создание превью текста через shorten().

Система должна показывать применение wrap() для получения списка строк.

Система должна демонстрировать добавление префиксов к тексту.

Система должна сохранять структуру параграфов при форматировании.

Система должна корректно обрабатывать неверный ввод пользователя.


## 4. Нефункциональные требования (ограничения)
Язык программирования: Python 3.8+

Используемые библиотеки: только стандартная библиотека Python (textwrap, argparse, pathlib)

Интерфейс: консольный (CLI) с интерактивным меню

Архитектура: модульная (разделение на core, utils, logic, presentation)

Код должен соответствовать PEP 8

Проект должен запускаться на Windows, Linux и macOS


## 5. Требования к интерфейсу
При запуске программы отображается главное меню с нумерованными пунктами.

Меню содержит следующие пункты:

📝 Форматирование абзацев (fill)

🧹 Удаление отступов (dedent)

✂️ Сокращение текста (shorten)

🔢 Разбивка на строки (wrap)

🏷️ Добавление префиксов

🚀 Полная демонстрация всех функций

❌ Выход

Пользователь выбирает пункт, вводя цифру от 0 до 6.
После выполнения демонстрации программа возвращается в главное меню.
Для выхода из программы используется пункт "0".


## 6. Входные и выходные данные
Входные данные:

Цифра от 0 до 6, введенная пользователем для выбора пункта меню

Для демонстраций — параметры форматирования (ширина строки, длина сокращения)

Выходные данные:

Исходный текст (до форматирования)

Отформатированный текст (после применения инструментов textwrap)

Статистика (количество строк, символов)

Сообщения о ходе выполнения демонстраций


## 7. Критерии приёмки (когда работа считается выполненной)
Работа считается выполненной, если:

Реализованы все функциональные требования из пункта 3.

Программа запускается командой python main.py без ошибок.

Все демонстрации работают корректно и показывают заявленный функционал.

Меню работает в цикле, корректно обрабатывает ввод и предоставляет выход.

Демонстрируется разница в тексте до и после форматирования.

Корректно сохраняется структура параграфов при необходимости.

Код разделен на модули согласно архитектуре (core, utils, logic, app).

Проект загружен в Git-репозиторий с полной структурой файлов.

В репозитории присутствует файл README.md с описанием проекта.

### Документация проекта
## Структура проекта

```
lib_textwrap/
├── python/           # Исходный код программы
│   ├── main.py       # Точка входа (запуск из IDLE или: python python/main.py)
│   ├── cli.py        # Парсинг аргументов и оркестрация
│   ├── formatter.py  # Форматирование через textwrap
│   └── file_handler.py  # Чтение/запись файлов, поиск .txt в папке
├── data/             # Входные файлы для программы
│   ├── sample.txt
│   ├── with_indent.txt
│   └── long_line.txt
├── Docs/             # Документация (overview, task, conclusions, sources — .docx)
└── README.md
```

## Тестовые данные

В папке **data/** лежат файлы для проверки:

| Файл | Назначение |
|------|------------|
| `sample.txt` | Обычный текст с абзацами для форматирования и проверки `--preserve-paragraphs` |
| `with_indent.txt` | Текст с общим отступом для проверки `--dedent` |
| `long_line.txt` | Одна длинная строка для проверки переноса по ширине |

## Общие выводы

- **textwrap** удобен для форматирования текста в консольных утилитах и при генерации простых текстовых отчётов; не требует установки пакетов.
- Основные плюсы: предсказуемое поведение, перенос по словам, dedent и префиксы «из коробки».
- Ограничения: нет переноса по слогам и сложной типографики; для таблиц или разметки нужны другие инструменты.
- В рамках проекта удалось собрать рабочую программу с разделением на модули и удобным запуском.
